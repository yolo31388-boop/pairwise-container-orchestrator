# 游戏内容器编排与调度系统

## 项目描述

游戏内容器编排与调度系统的bug修复项目。核心模块 `container/orchestrator.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 容器调度只用轮询不考虑资源和负载
- 资源管理完全没做CPU和内存超配了也不知道
- 服务发现完全没做容器IP变了就找不到
- 自动扩缩容完全没做流量高峰来了不能自动扩容
- 滚动更新完全没做更新时所有容器同时重启

## 运行测试

```bash
python -m pytest tests/test_container_orchestrator.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
